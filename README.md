# ELIXARA Perfume & Attar

A modern, responsive, and SEO-friendly perfume & attar business website built using HTML5, Tailwind CSS, and Vanilla JavaScript.

This website is designed for local perfume businesses, attar shops, fragrance stores, and small retail perfume brands that want a clean, classic, and professional online presence.

---

- Fully Responsive Design
- Mobile Friendly Layout
- SEO Optimized Structure
- Geo-Friendly Local Business Website
- WhatsApp Integration
